# Averen Technologies

> **Building Digital Products. Empowering Ideas.**

Official company website for **AVEREN TECHNOLOGIES** — a digital product and technology studio specializing in Web Development, Application Development, MVP & Prototype Development, Custom Software Solutions, and Creative & Digital Design.

---

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, React 18)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)

---

## Features

- **Responsive Design**: Optimized for 4K, 1536px, 1440px desktop screens, tablets, and mobile devices.
- **Hero Section**: Commanding two-column layout with high-resolution Averen Technologies brand asset.
- **Services Showcase**: 5 service offerings with interactive enquiry routing.
- **Our Work / Portfolio**: Live project showcases including Ani's Cakes, Personal Portfolio, and ZipBi with direct links.
- **Pricing & Offerings**: Transparent pricing tiers (Creative & Design, Websites & Digital Solutions, Special Student Offers) and custom project negotiation banner.
- **About Studio**: Mission, Vision, and Core Values pillars.
- **Contact Enquiry System**: Validated contact form connected to an internal API handler.

## Getting Started

### Prerequisites

- Node.js (v18.17.0 or later)
- npm, pnpm, or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Amarnath2007/Averen.git
   cd Averen
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
